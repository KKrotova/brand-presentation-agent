# Предпочтения пользователя — рабочая память

> Зафиксировано по предыдущим замечаниям пользователя. Это предпочтения для будущих проектов, не замена конкретному новому брифу.

## Общий стиль
- Премиально, современно, эстетично, с выразительными маркетинговыми клеймами.
- Не «топорные» шаблонные слайды; больше качественной визуальной подачи и аппетитных блюд.
- Сохранять все важные факты исходной презентации при полной переработке композиции.
- Для «Пава-Пава» использовать брендовые Pantone 640 C и Pantone 2995 C.
- Не использовать дешёвые голубые волны, полотенца, вензеля и случайные небрендовые элементы.

## Продукт и фуд-стайлинг
- Реалистичная индейка: натуральная, сочная, аппетитная, без искусственного вида.
- Стейки — не толстые и не пережаренные; это должны быть именно стейки индейки, а не грудка.
- Не оставлять тарелку визуально пустой; гарнир премиальный, натуральный.
- Котлеты не должны выглядеть сухими; без гриль-полос.
- Овощи и зелень без гриль-полос; не использовать листовой салат, петрушку и укроп.
- Не перегружать композиции горошком и мини-кукурузой, если они выглядят неподходяще.

## Процесс согласования
- Агент работает как исполнитель и самостоятельно делает черновой результат.
- Важные изменения фактов, позиционирования, бренд-стандартов и внешняя публикация требуют согласования.
- Новые предпочтения записывать только после подтверждения пользователя.
